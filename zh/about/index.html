关于

我是一个软件开发者和翻译者。

翻译书籍

  • 《笨办法学Python》/《笨办法学Python3》— 广受初学者欢迎的Python学习书籍，人民邮电出版社出版。
  • 《笨办法学C语言》、《笨办法学Ruby》、《笨办法学Python进阶版》— 同系列书籍。人民邮电出版社出版。
  • 《极端生存》— 一本讲海洋生命的科普书籍。湛卢文化/浙江人民出版社出版。

开源软件项目

  • junitparser — 用 Python 写的用来处理 JUnit 以及类似格式文件的库。当初是为了解决工作问题而写，现在应该是同类库中最受欢迎的一个，目前已经被纳入Debian发行版中。
  • silabacion — TypeScript写的西班牙语单词音节化库。这个库是学西班牙语的时候写的。

翻译项目

  • KGS的网站和客户端。KGS 是一个在线围棋平台，目前隶属美国围棋协会。
  • Requests 中文文档 的主要贡献者。Request是最受欢迎的Python HTTP工具库。
  • Perfect Ear的早期版本。Perfect Ear是安卓最受欢迎的练耳工具。
  • 《古诗外译集》——一本将外文翻译的中文古诗再翻译成中文的书。
